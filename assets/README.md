# Assets Directory

This directory should contain the following image assets:

## Required Assets

- **icon.png**: 1024x1024 app icon
- **splash.png**: 1284x2778 splash screen image
- **adaptive-icon.png**: 1024x1024 Android adaptive icon
- **favicon.png**: 48x48 web favicon

## Temporary Placeholders

For development, you can use simple placeholder images or generate them using an online tool.

The app will function without these assets, but you'll see warnings in the console.

## Generating Assets

You can use tools like:
- Figma
- Canva
- Adobe Illustrator
- Or any image editing software

Colors to use (from theme):
- Primary: #FF2D55
- Secondary: #007AFF
- Background: #F2F2F7
